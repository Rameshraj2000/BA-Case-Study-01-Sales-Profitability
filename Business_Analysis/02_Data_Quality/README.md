# Data Quality Assessment

This section documents the data quality checks performed before the business analysis.

## Checks Performed

- Missing value assessment
- Duplicate record assessment
- Data completeness review
- Identification of potential data quality risks

## Key Findings

The assessment identified missing values in the dataset, including records associated with the 2018 data.

Duplicate records were also identified and reviewed as part of the initial data-quality assessment.

## Impact on Analysis

The identified data-quality issues were considered when interpreting the SQL analysis and dashboard results.

The analysis therefore distinguishes observed findings from assumptions and limitations where the available data does not provide enough evidence for a definitive conclusion.
