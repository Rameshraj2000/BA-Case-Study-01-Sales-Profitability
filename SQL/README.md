# SQL Analysis

This folder contains the SQL analysis used to investigate sales performance, profitability, discount exposure and product-level losses.

## Analysis Areas

- Data quality assessment
- Regional profitability
- Category and sub-category profitability
- Discount impact on profit margin
- Product-level loss analysis
- Cross-dimensional analysis

## Purpose

SQL was used to validate the dataset, calculate business KPIs, identify profitability patterns and support the findings presented in the Power BI dashboard.

Detailed SQL queries and supporting analysis will be maintained in this folder.
